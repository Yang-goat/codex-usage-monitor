## v0.1.3

增加端口与进程生命周期防护，以及紧凑的齿轮设置面板。

### 更新内容

- 启动器使用系统互斥锁，辅助进程使用命名管道保证单实例，避免重复启动竞争。
- 端口释放过程有限重试，核验监听地址和进程归属；不自动换端口或终止占用者。
- 客户端退出后清理连接、状态条和额度查询子进程；重启等待旧辅助进程退出后再启动。
- 最右侧齿轮显示进程名、PID、调试端口、客户端 PID、连接状态及运行时间，提供立即关闭和重启。
- 面板移除小字说明和空提示占位；保留主聊天绑定、统计口径以及 Dot、侧边聊天隐藏规则。
- 保留自定义安装路径、端口及运行目录支持，重启状态文件改为原子替换。

### 下载与更新

下载 `codex-usage-monitor-v0.1.3-windows.zip` 和 `SHA256SUMS.txt`，校验后按 [README](https://github.com/Yang-goat/codex-usage-monitor#readme) 更新。

需要 Windows 10/11、PowerShell 5.1+ 和 Node.js 22+。ZIP 是源码运行包，无需安装 npm 生产依赖。更新前保留旧安装备份，待当前任务完成后正常退出客户端再替换文件。

关闭或重启按钮仅控制状态条辅助进程。调试端口由 Codex 客户端持有，客户端完全退出后才释放。

16 项 Node 测试、24 项启动检查、安装恢复测试和发布扫描通过；GitHub Actions 在 Node.js 22、24 下通过。独立模拟页面验证齿轮面板、进程信息和关闭／重启命令；发布包仅包含 Git 跟踪源码，不含本机配置、运行记录或真实会话。
