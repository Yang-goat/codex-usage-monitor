## Codex 用量监控 v0.1.1

修复 Dot 对话页误显示用量状态条的问题。

### 修复内容

- 排除主窗口 Dot 消息组件中复用的代理输入框。
- Dot 快捷小窗保持隐藏，支持 URL 路径与 `initialRoute` 两种路由形式。
- 升级时清除旧状态条及展开面板，正常 Codex 和 ChatGPT Work 聊天继续显示。
- 增加 Dot 模拟预览与独立浏览器回归检查。

### 下载与更新

下载 Assets 中的 `codex-usage-monitor-v0.1.1-windows.zip` 和 `SHA256SUMS.txt`，核对 SHA-256 后按 [README](https://github.com/Yang-goat/codex-usage-monitor#readme) 更新。

需要 Windows 10/11、PowerShell 5.1+、Node.js 22+。ZIP 是源码运行包；无需安装 npm 生产依赖。

保留旧安装目录的 `runtime/` 备份，等待当前任务完成后正常退出 Codex，再按 README 的更新方式安装。客户端不会被安装器强制关闭。

### 验证范围

独立浏览器模拟检查覆盖主窗口 Dot、快捷窗路由、旧版问题复现、热替换、Codex/Work/普通聊天及切换恢复。另执行 Node 源码测试、PowerShell 安装恢复模拟检查与发布内容扫描。

本次不在真实客户端中切换模式、发送消息或重启客户端；客户端结构适配范围仍为 Windows 商店版 26.1027。
