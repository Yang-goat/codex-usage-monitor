## Codex 用量监控 v0.1.0

首个正式版本：在 Codex 和 ChatGPT Work 输入框中查看聊天 token、缓存命中率、上下文占用、账号额度与重置倒计时。

### 下载与安装

1. 下载本页 Assets 中的 `codex-usage-monitor-v0.1.0-windows.zip` 和 `SHA256SUMS.txt`。
2. 使用 `Get-FileHash -Algorithm SHA256 <ZIP路径>` 核对 ZIP 哈希与校验文件一致。
3. 解压到长期保留的目录，打开 PowerShell，进入解压后的项目目录。
4. 执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install.ps1`。
5. 等现有任务结束后，正常退出全部 Codex 实例，再从接入的桌面图标重开。

需要 **Windows 10/11、PowerShell 5.1+、Node.js 22+**，并已安装、登录 Codex 桌面端。ZIP 是源码运行包，没有捆绑 Node.js；无需 `npm install`。CLI 可选，缺失时额度可能使用日志快照。

### 主要功能

- 单行显示 `数值 tok`、缓存命中率、上下文、额度与紧凑倒计时。
- 点击展开 Token/上下文明细，使用 K/M/B 缩写；悬停查看完整整数。
- 自动跟随可见代理输入框，普通 ChatGPT 聊天隐藏。
- 桌面图标联动启动和退出，安装前备份原快捷方式，卸载时校验并恢复。

### 使用范围

当前为简体中文界面，适配基于 Windows 商店客户端 26.1027 的输入框结构；其他客户端版本需要实际核验。本地没有对应日志的云端聊天可能显示未知统计。客户端 DOM、日志或调试接口变化时可能需要更新适配。

源码、安装恢复模拟测试和 GitHub Actions 检查不代表所有客户端版本均已完成界面验证。

完整用法、真实截图、卸载方法和可复制的 AI Agent 自动配置提示词见 [README](https://github.com/Yang-goat/codex-usage-monitor#readme)。
