## v0.1.2

状态条固定显示在主聊天，解决聚焦侧边聊天时位置和统计归属随之切换的问题。

### 修复内容

- 排除侧边聊天标签页及右侧面板中的输入框，取消按输入焦点优先绑定。
- 状态条位置、token 和上下文占用始终对应可见主聊天。
- 主聊天不可见时隐藏；尚无聊天 ID 时显示未知值，不使用侧边聊天的 ID 或统计。
- 保留 Codex、ChatGPT Work 的主聊天显示，以及普通聊天和 Dot 的隐藏规则。

### 下载与更新

下载 Assets 中的 `codex-usage-monitor-v0.1.2-windows.zip` 和 `SHA256SUMS.txt`，核对 SHA-256 后按 [README](https://github.com/Yang-goat/codex-usage-monitor#readme) 更新。

需要 Windows 10/11、PowerShell 5.1+、Node.js 22+。ZIP 是源码运行包，无需安装 npm 生产依赖。按 README 保留旧安装备份，待当前任务完成后正常退出客户端再更新。

### 验证范围

使用独立 Playwright 模拟页面检查主/侧聊天焦点切换、主聊天 token 来源、侧边容器排除、缺少主聊天 ID 及 Dot 等原有行为；另执行 Node 测试、PowerShell 安装恢复模拟检查和发布扫描。

侧边聊天可能是只保存在内存中的临时分支，当前版本仅统计主聊天，不合并侧边聊天的用量。账号额度仍为共享额度。
