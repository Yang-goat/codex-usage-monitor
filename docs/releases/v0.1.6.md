# v0.1.6

## 简体中文

修复通过监控快捷方式启动 Codex / ChatGPT 后任务栏图标变成空白的问题。

- 启动时补齐窗口大小图标、任务栏图标资源及应用标识；窗口重建或图标被重置后自动恢复。
- 将快捷方式图标缓存到本机 `runtime/icons/`，商店升级移除旧安装目录后仍可显示。
- 图标辅助进程按客户端保持单实例，随客户端退出；开机自启设置保持不变。

下载 Windows ZIP 和 `SHA256SUMS.txt`，校验并解压到长期目录后运行 `scripts/Install.ps1`。保留现有 `runtime/` 备份。修复通过监控快捷方式启动时生效。

## English

Fixes blank Windows taskbar icons when Codex / ChatGPT is started through the monitor shortcut.

- Restores window icons, taskbar icon resources, and app identity; repairs recreated windows and later icon resets.
- Caches shortcut icons in local `runtime/icons/` so Store upgrades do not invalidate old icon paths.
- Runs one hidden icon helper per desktop process and releases it when the desktop exits. Windows sign-in startup settings are unchanged.

Download the Windows ZIP and `SHA256SUMS.txt`, verify the checksum, extract to a permanent directory, and run `scripts/Install.ps1`. Preserve existing `runtime/` backups. The repair applies when launching through the monitor shortcut.

Requires Windows 10/11, PowerShell 5.1+, and Node.js 22+. No npm install is required.
