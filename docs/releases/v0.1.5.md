## v0.1.5

### 简体中文

- 状态条启动时检查 GitHub 正式版本。发现可校验的 Windows 包后，点击「自动更新」即可安装。新版辅助进程启动失败时恢复上一版。
- 齿轮面板支持简体中文和 English，保存语言选择，并以产品名作为标题。
- 双语 README 增加快速安装入口、设置预览和问题报告表单。
- 精简 Windows ZIP，仅包含运行和安装所需文件、许可证与简明安装说明。

从此前发布的 `v0.1.4` ZIP 升级，请下载 `codex-usage-monitor-v0.1.5-windows.zip` 和 `SHA256SUMS.txt`，校验后按 [中文 README](https://github.com/Yang-goat/codex-usage-monitor#readme) 手动更新一次。之后可在设置中安装新版。需要 Windows 10/11、PowerShell 5.1+ 和 Node.js 22+。

### English

- The monitor checks for stable releases on startup. Select **Auto-update** when a verifiable Windows package is available. The helper falls back to the previous version if the replacement fails to start.
- The settings panel shows the product name and remembers your choice of English or Simplified Chinese.
- Bilingual READMEs include quick-start instructions, settings previews, and an issue form.
- The smaller Windows ZIP includes the runtime, installation scripts, license, and offline setup instructions.

To upgrade from the published `v0.1.4` ZIP, download `codex-usage-monitor-v0.1.5-windows.zip` and `SHA256SUMS.txt`, verify the checksum, and follow the manual upgrade steps in the [English README](https://github.com/Yang-goat/codex-usage-monitor/blob/main/README.en.md). Future releases can be installed from the settings panel. Requires Windows 10/11, PowerShell 5.1+, and Node.js 22+.
